# 🏠 StayHub – Online Home Rental and Booking Management System

## 📌 About the Project

StayHub is a web-based **Online Home Rental and Booking Management System** designed to simplify the process of property listing, searching, and booking.

The platform allows property owners or hosts to list and manage their properties, while guests can search for suitable accommodations, view property details, and make bookings. The system also includes administrative functionality for managing users and overall platform activities.

The project aims to provide a centralized and user-friendly solution for managing rental properties and bookings efficiently.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have the following installed:

* WAMP Server
* PHP
* MySQL
* A modern web browser

### Steps

1. Clone this repository:

```bash
git clone https://github.com/your-username/stayhub.git
```

2. Move the project folder to the WAMP server directory:

```text
C:\wamp64\www\
```

3. Start the WAMP Server.

4. Open phpMyAdmin and create the required database.

5. Import the project database file into MySQL.

6. Update the database configuration file with your database credentials.

7. Open your browser and run the project:

```text
http://localhost/stayhub/
```
